# Суфлёр 9:16 Studio

> Автономный телесуфлёр и видеорекордер для macOS, созданный специально для съёмки вертикальных видео (**Reels**, **Shorts**, **TikTok**).

Позволяет уверенно говорить на камеру, глядя прямо в объектив, без необходимости заучивать текст наизусть или монтировать дубли вручную.

---

## ✨ Возможности

- **Идеальный зрительный контакт:** Текст суфлёра расположен у самого верхнего края экрана ровно под камерой ноутбука или монитора (`▲ КАМЕРА ЗДЕСЬ ▲`). Взгляд всегда направлен в объектив.
- **3 режима движения текста:**
  - **Постоянная скорость** — классический равномерный скролл с настраиваемой скоростью (слов в секунду).
  - **По голосу** — текст движется, пока вы говорите, и мягко останавливается на паузах.
  - **Слово в слово** — отслеживание речи через встроенный движок распознавания macOS (`SFSpeechRecognizer`).
- **Автоматический кроп в 9:16 (1080×1920):** После завершения дубля видео аппаратно пережимается через `ffmpeg` (`h264_videotoolbox` на Apple Silicon) в вертикальный формат.
- **Безопасные зоны соцсетей:** Оверлей интерфейса Reels и TikTok (кнопки лайков, комментариев и нижняя зона субтитров/описания), чтобы композиция кадра не перекрывалась интерфейсом приложения.
- **Поддержка любых камер:**
  - Встроенная камера FaceTime HD.
  - **iPhone по Type-C или Wi-Fi** через встроенную в macOS *Непрерывную камеру (Continuity Camera)*.
  - **Android по Type-C** (режим «Веб-камера» в Android 14+ или через Camo / DroidCam).
  - Любые внешние USB веб-камеры (UVC).
- **Пульт с телефона по QR:** Управляйте записью, скоростью и сменой текста с экрана смартфона без установки сторонних приложений (работает по локальной сети через защищённый токен).
- **Голосовые команды:** Управление дублями голосом: *«Мотор»*, *«Стоп»*, *«Снято»*, *«Заново»*, *«В корзину»*. Защищено от случайных срабатываний, если фраза встречается в самом сценарии.
- **Быстрый импорт и авто-разбивка:** Перетаскивание файлов `.txt` / `.md` (Drag & Drop) и кнопка «Разбить на строки» для деления длинных предложений на ритмичные фразы по 3–5 слов.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| <kbd>Пробел</kbd> | Старт / пауза скролла текста |
| <kbd>Enter</kbd> | Завершить запись и сохранить ролик |
| <kbd>Esc</kbd> | Остановить запись и выбросить дубль |
| <kbd>P</kbd> | Репетиция (прокрутка текста без включения записи) |
| <kbd>M</kbd> | Переключение режима (*Скорость / Голос / Слова*) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Изменение скорости скролла (±0.25 сл/с) |
| <kbd>+</kbd> / <kbd>−</kbd> | Размер шрифта текста |
| <kbd>Home</kbd> | Возврат в самое начало текста |
| <kbd>G</kbd> | Показать/скрыть безопасные зоны Reels и TikTok |
| <kbd>H</kbd> | Скрыть боковые панели (чистый вид) |
| <kbd>F</kbd> | Полноэкранный режим |

## 🚀 Установка и запуск

### Вариант 1. Готовый `.dmg`
1. Скачайте образ `Суфлёр.dmg` из раздела [Releases](https://github.com/MarvelTrade/suflyor/releases).
2. Перетащите **Суфлёр** в папку **Программы** (`/Applications`).
3. При первом запуске нажмите правой кнопкой мыши по приложению → **«Открыть»** → подтвердите запуск.
4. Выдайте разрешения на доступ к Камере, Микрофону и Распознаванию речи.

### Системные требования:
- **macOS:** 13.0 (Ventura) или новее (Apple Silicon M1/M2/M3/M4 или Intel).
- **ffmpeg:** Для авто-кропа в 9:16 требуется установленный `ffmpeg`. Если его нет:
  ```bash
  brew install ffmpeg
  ```

## 🛠 Сборка из исходников

Для сборки требуется macOS с установленными Command Line Tools (`swiftc`, `python3`, `iconutil`):

```bash
# Клонирование репозитория
git clone https://github.com/MarvelTrade/suflyor.git
cd suflyor

# Сборка Суфлёр.app
chmod +x build.sh
./build.sh

# Или сборка приложения вместе с установочным образом .dmg:
./build.sh --dmg
```

Готовое приложение появится в каталоге `build/Суфлёр.app`.

## 📂 Где сохраняются записи

- Готовые вертикальные ролики: `~/Movies/Суфлёр/`
- Сырые несжатые исходники записи: `~/Movies/Суфлёр/исходники/`
- Сценарии и заметки: `~/Movies/Суфлёр/Сценарии/`

В интерфейсе приложения в любой момент можно нажать кнопку **«Папка с видео»** для перехода к файлам в Finder.
